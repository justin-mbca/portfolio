## 📝 Customization

### Update Personal Information
Edit `index.html`:
- Line 15: Update page title
- Line 35: Add your name
- Lines 180-185: Update contact info

### Add Your Photo
Replace `images/profile-placeholder.jpg` with your photo (recommended: 400x400px)

### Modify Colors
Edit `css/style.css`:
- Lines 5-20: CSS custom properties for colors

## 🚀 Local Development

```bash
# Clone the repository
git clone https://github.com/justin-mbca/portfolio.git
cd portfolio

# Open in browser
open index.html

# Or use a local server
python -m http.server 8000
# Visit http://localhost:8000
```
