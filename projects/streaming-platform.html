Healthcare Data Streaming Platform

Real-Time Medical Device Integration at Scale

Apache Kafka Apache Flink Spark Streaming AWS Kinesis AWS MSK AWS IoT Core Docker Terraform HL7 FHIR
View on GitHub Documentation

Overview

Built a production-grade streaming platform for real-time medical device integration, processing 10K+ messages per second with sub-50ms latency. The platform supports HL7 v2, FHIR R4 streaming, and provides real-time clinical alerting through complex event processing.

Challenge

Healthcare organizations need to:

  • Process real-time data from medical devices
  • Support multiple healthcare data standards (HL7, FHIR)
  • Detect critical events for clinical alerts
  • Scale to handle thousands of devices
  • Ensure HIPAA compliance
  • Maintain sub-second latency

Solution

Production streaming platform with:

  • Apache Kafka for high-throughput message ingestion
  • Apache Flink for real-time CEP and alerting
  • Spark Streaming for batch analytics
  • AWS IoT Core for medical device connectivity
  • HL7/FHIR parsers and transformers
  • Docker/Kubernetes for containerized deployment

Data Flow

  1. Ingestion: Medical devices connect via AWS IoT Core (MQTT/HTTPS)
  2. Streaming: Messages published to Kafka topics by data type
  3. Processing: Flink jobs perform real-time CEP for critical events
  4. Alerting: Critical patterns trigger clinical alerts (SNS/PagerDuty)
  5. Analytics: Spark jobs perform batch aggregations and analytics
  6. Storage: Data persisted to time-series DB and data lake

Code Samples

Flink CEP Job (Scala)

import org.apache.flink.cep.scala.CEP
import org.apache.flink.cep.scala.pattern.Pattern
import org.apache.flink.streaming.api.scala._

// Define pattern for critical cardiac event
val criticalCardiacPattern = Pattern
  .begin[VitalSign]("first")
  .where(_.heartRate > 120)
  .next("second")
  .where(_.heartRate > 130)
  .within(Time.seconds(30))

// Apply pattern to stream
val vitalStream: DataStream[VitalSign] = env
  .addSource(new FlinkKafkaConsumer[VitalSign](
    "vital-signs",
    new VitalSignSchema(),
    kafkaProps
  ))

val patternStream = CEP.pattern(
  vitalStream.keyBy(_.patientId),
  criticalCardiacPattern
)

// Handle detected patterns
val alerts = patternStream.select { pattern =>
  val events = pattern.get("first") ++ pattern.get("second")
  ClinicalAlert(
    patientId = events.head.patientId,
    alertType = "CRITICAL_TACHYCARDIA",
    severity = "HIGH",
    timestamp = System.currentTimeMillis()
  )
}

// Send alerts to SNS
alerts.addSink(new SNSAlertSink())

Kafka Producer (Python)

from kafka import KafkaProducer
import json
import hl7

# Configure Kafka producer
producer = KafkaProducer(
    bootstrap_servers=['kafka-broker-1:9092', 'kafka-broker-2:9092'],
    value_serializer=lambda v: json.dumps(v).encode('utf-8'),
    compression_type='snappy',
    acks='all',
    retries=3
)

def send_hl7_message(hl7_message: str):
    """Parse and send HL7 message to Kafka"""
    # Parse HL7 message
    parsed = hl7.parse(hl7_message)
    
    # Extract key fields
    message_data = {
        'message_type': str(parsed.segment('MSH')[9]),
        'patient_id': str(parsed.segment('PID')[3]),
        'timestamp': str(parsed.segment('MSH')[7]),
        'raw_message': hl7_message
    }
    
    # Send to appropriate topic
    topic = f"hl7-{message_data['message_type'].lower()}"
    producer.send(topic, value=message_data)
    producer.flush()

def send_fhir_observation(observation: dict):
    """Send FHIR observation to Kafka"""
    producer.send('fhir-observations', value=observation)
    producer.flush()
